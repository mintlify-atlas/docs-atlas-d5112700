OASIS Seguros is a complete insurance brokerage management system built with Next.js 16, React 19, Prisma ORM, and PostgreSQL. It gives agents and administrators a unified workspace to manage client lifecycles, policy workflows, payment schedules, and automated multi-channel notifications — all running on a clean, containerized stack.

## Get Up and Running

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/JohannCaizaguano/OasisSeguros.git
    cd OasisSeguros
    ```
  </Step>
  <Step title="Configure environment variables">
    Copy the example environment file and set your database, Redis, and auth secret:
    ```bash
    cp app/.env.example app/.env
    ```
    At minimum set `DATABASE_URL`, `REDIS_URL`, and `BETTER_AUTH_SECRET` (32+ characters).
  </Step>
  <Step title="Start all services with Docker">
    ```bash
    docker-compose up -d
    docker-compose exec web npm run db:migrate
    docker-compose exec web npm run db:seed
    ```
  </Step>
  <Step title="Open the application">
    Navigate to [http://localhost:3000](http://localhost:3000). The seeded admin credentials are available in `prisma/seed.ts`.
  </Step>
</Steps>

## Technology Stack

| Layer | Technology |
|---|---|
| Frontend / API | Next.js 16, React 19 |
| Database | PostgreSQL 15 + Prisma ORM |
| Cache / Sessions | Redis |
| Authentication | Better-Auth |
| Background Jobs | pg-boss |
| Email | Resend / SMTP (Nodemailer) |
| SMS | Twilio |
| UI Components | Shadcn UI + Tailwind CSS 4 |
| Containerization | Docker + Docker Compose |

<Note>
  OASIS Seguros is designed for production use with Docker. See the [Docker deployment guide](/infrastructure/docker) for production configuration.
</Note>
